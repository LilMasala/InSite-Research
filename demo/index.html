How context enters the model

Sleep and cycle

Context-dependent sensitivity modifies insulin action. Sleep also affects glucose production. Cycle effects use the model’s recorded-day phase mapping.

Exercise and site age

Exercise changes glucose uptake during activity and sensitivity afterward. Site age has its own fitted sensitivity coefficient.

Personal physiology

Fitting adjusts insulin sensitivity, glucose production, and absorption parameters. The library also estimates day-to-day variation and residual responses.

Interactive comparisons use the model’s prior context coefficients. Basal and bolus delivery are fixed by each scenario. The calibration example below shows a separate fit to synthetic observations. The documentation records each mechanism, parameter, and evaluation limit.
