# Publication review

The portfolio is maintained in the private GitHub review repository `LilMasala/InSite-Research`. Review the motivation, ownership description, and research interpretation in the README before sharing it with admissions readers.

The publication directory is this folder alone. Its source manifests, synthetic examples, screenshots, and documentation form the intended release. Keep the private working repository and its history separate.

Before making the repository public:

1. Review the README in your own voice and confirm the name and description you want to use.
2. Confirm a reuse license for the original portfolio and pattern files. The twin subtree already retains its existing Apache 2.0 license.
3. Run `python scripts/check_portfolio.py` and inspect the file list.
4. Confirm that the private review repository contains the intended files and approve its public visibility.
5. Check the rendered README images, documentation links, and saved-example download from the public repository.

The synthetic examples can be published with this draft after review. Real participant reports, credentials, model weights, and source datasets stay outside this directory. Benchmark metrics from research data need verified aggregate provenance before being added as headline results.
